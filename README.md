# Lab 1: I Am Rich

## Mô tả

Ứng dụng Flutter cơ bản hiển thị một viên kim cương và dòng chữ “I Am Rich”. Bài lab giúp làm quen với cấu trúc ứng dụng và cách khai báo ảnh trong `pubspec.yaml`.

## Chức năng

- Hiển thị ảnh diamond từ assets
- Hiển thị tiêu đề ở giữa màn hình
- Giao diện Material đơn giản

## Công nghệ

- Flutter
- Dart

## Cách chạy

```bash
flutter pub get
flutter run
```
